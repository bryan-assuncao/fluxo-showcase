## Sobre o projeto

O **OS Flow** centraliza o atendimento, a precificação e o acompanhamento da produção de uma empresa de comunicação visual. O sistema permite acompanhar cada ordem de serviço desde o recebimento até a entrega, com uma visão clara de prazos, valores e responsabilidades.

Este repositório é somente uma apresentação do produto. O código-fonte não está incluído.

## Como funciona

1. **Cadastre clientes e produtos** com informações comerciais, medidas e valores.
2. **Crie uma ordem de serviço** selecionando o cliente, os itens, as dimensões e o prazo.
3. **Anexe a arte do pedido** em imagem ou PDF para centralizar as referências da produção.
4. **Acompanhe a produção** pelo quadro visual, movendo cada OS entre as etapas.
5. **Consulte e imprima a OS** com valores, saldo, histórico e informações de entrega.
